# STOLAR CARP Android APK

Цей пакет додає Android-оболонку до чинного сайту `https://stolarcarp.netlify.app/`.
Вебінтерфейс завантажується з Netlify, тому зміни сайту з'являються в застосунку
після наступного відкриття/перезавантаження без перевипуску APK.

## Як додати до репозиторію

1. Розпакуйте архів у корінь репозиторію `DK-PRIME/stolarcarp-site`.
2. Переконайтеся, що папки `android-app/` та `.github/workflows/` лежать у корені
   поруч з `index.html`, а не всередині папки сайту.
3. Закомітьте й відправте файли в GitHub.
4. Відкрийте вкладку **Actions** → **Build STOLAR CARP APK**.
5. Після успішної збірки відкрийте запуск workflow і завантажте artifact
   **STOLAR-CARP-APK**. Усередині буде `app-debug.apk`.
6. Передайте APK на Android-телефон і встановіть його. Android може попросити
   дозволити встановлення з цього джерела.

## Важливо

- Для завантаження сайту потрібен інтернет.
- Контент сайту оновлюється з Netlify; нативні зміни APK (іконка, дозволи,
  Java-код, package ID) потребують нової збірки.
- Це debug-підписаний APK для тестування та прямого встановлення, не реліз для Google Play.
- Перевірте у готовому застосунку вхід/реєстрацію Firebase, кабінет, Live,
  завантаження файлів і переходи між сторінками.
- Якщо у Firebase Authentication увімкнений Google Sign-In, його окремо треба
  протестувати у WebView: деякі OAuth-провайдери обмежують вбудовані браузери.
- Для публікації в Google Play потрібно налаштувати release keystore, підписаний
  AAB та актуальні вимоги Google Play.

## Технічні параметри

- Назва: STOLAR CARP
- Application ID: `com.stolarcarp.app`
- Мінімальна Android-версія: Android 6.0 (API 23)
- Target SDK: 34
- Web URL: `https://stolarcarp.netlify.app/`
